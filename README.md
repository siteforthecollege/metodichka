# Методический кабинет преподавателя

Статический сайт за 2025–2026 учебный год. ФИО меняется в `site.json` (поле `teacher`), затем GitHub Actions пересобирает сайт.

24 учебно-методических материала: 4 по каждой из двух дисциплин, 4 по каждому виду практики в каждом семестре. Материалы представлены полным текстом, доступны для скачивания в Markdown и печати. Источники приведены на страницах материалов. Это самостоятельно составленные учебные разработки со ссылками на документацию, а не копии чужих пособий.

## Даты

Даты карточек заданы владельцем как календарное размещение материалов за учебный год. Они не подтверждают фактическую дату запуска сайта, публикации в интернете или непрерывную годовую работу. История GitHub и развертываний сохраняет реальные даты. Для подтверждения стажа сайта нужны реальные архивные сведения.

Учебные границы: первый семестр 01.09–31.12.2025, второй 12.01–31.07.2026. Последний день июля принят как конец второго семестра, поскольку точный день не указан. Публикации не попадают в первые и последние 12 дней семестров. Практики — ноябрь–декабрь и июнь–июль.

## Публикация

Workflow `.github/workflows/pages.yml` собирает `dist` и публикует через GitHub Pages. Источник Pages в настройках репозитория должен быть GitHub Actions. Никаких пользовательских токенов в исходниках нет.

## Обратная связь и посещаемость

Обратная связь открывает предварительно заполненное обращение в GitHub Issues; для отправки нужен GitHub-аккаунт. Письма автоматически не отправляются. Поле `email` позволяет добавить контактный адрес.

Статистика посещений не выдумывается и не заменяется локальным счетчиком. После подключения реального сервиса аналитики его публичный отчет можно указать в `analyticsUrl`. Само указание ссылки не устанавливает сбор статистики: код выбранного сервиса нужно добавить отдельно согласно его инструкции. До подключения на сайте нет неподтвержденных цифр. Для аттестации потребуются реальные данные и заверение работодателем, как указано в критерии.

## Локальная сборка

`python3 build.py` — сборка без сторонних зависимостей. `python3 validate.py` — проверка календаря, комплектности и внутренних ссылок.
